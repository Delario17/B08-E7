# E11 使用的接口契约

版本为 e11e12-1。E11 B 请求指定 mode=e11-b、repo、base、target、candidate、fixed_report、expected_output 和 build_timeout。

固定报告要求 kind=fixed-md、status=SUCCEEDED，外层 commit 和 data.commit 均等于实际 target 完整 SHA。版本不匹配返回 STALE_REPORT 并停止修复。

输出阶段为 draft、fixed-md、repair、recheck，共享 job_id/trace_id，产物使用 artifact:// URI、SHA-256 和 bytes。成功需真实镜像输出符合预期、补丁验证接受及最终动态重检无 MISSING。对应个人测试见 test_student_241250008.py。
