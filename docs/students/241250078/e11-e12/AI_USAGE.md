## 建议与采纳

工具建议先以最新 `main` 为基线，只复用组内 E11–E12 公共运行器，再增加可明确归属的个人测试和报告；该建议已采纳。工具还建议将 Docker CLI 和课程样例的镜像地址统一改为带 digest 的镜像站地址，以处理服务器访问 Docker Hub 超时且不牺牲可复现性；该建议经实际构建验证后采纳。

个人测试选择“服务重启后幂等绑定仍有效”，覆盖同键同请求复用和同键不同请求冲突，避免与已有简单幂等测试重复。真实项目使用 B08 已有 E3 Target，不用纯玩具工程替代课程项目。

## 人工核对

本人核对了分支、提交范围、每个 job/trace、base/target、补丁哈希和失败错误码。所有结果均由服务器上的实际命令生成；报告中的 `SUCCEEDED`、`STALE_REPORT`、HTTP 409 和 12 项测试结果均与原始 JSON 或测试输出一致。临时 `data/` 和 `work/` 不提交到 Git，关键证据另行归档，避免嵌套仓库和构建产物污染代码历史。
