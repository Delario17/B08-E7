## 1. 请求字段

| 字段 | 含义与本次约束 |
|---|---|
| mode | `e11-b`，DRAFT 接固定 MD 的 B轨道流程 |
| repo | 容器视角下的受测 Git 仓库路径 |
| base / target | 可解析的受测项目提交；分别记录，允许两者不同 |
| candidate | 候选 Dockerfile 文件路径 |
| fixed_report | 固定 MD 封装报告路径 |
| expected_output | 本次为字符串 `1` |
| build_timeout | 本次为 7200 秒，用于单次 Docker 构建命令 |
| --out | 仓库 work/ 下新的输出子目录；非空目录拒绝覆盖 |

请求路径由宿主入口映射到 `/course/` 视角。个人准备脚本保存的路径供容器中的 pipeline 消费。

本次 direct 的 target 为 `9b56751da35cd713c003eb79ca0927b218335fbf`；mixed 的 target 为 `b2a941f2c38548779dce0ab663a7d773c315eeff`。二者固定报告分别绑定自己的目标版本。

## 2. 固定 MD 输入

外层封装包含：

| 字段 | 约束 |
|---|---|
| schema_version | `e11e12-1` |
| kind | `fixed-md` |
| status | `SUCCEEDED` |
| commit | 必须等于解析后的 target_commit |
| data | 内层依赖报告，供 MDFixer 消费 |
| data.commit | 必须同样等于 target_commit |
| data.findings | 本次包含 main.o 对 config.h、extra.h 的 MISSING，以及 unused.h 的 REDUNDANT |

输入固定报告由准备脚本生成；阶段输出再补充 job_id、trace_id 和 artifacts。补丁生成仅处理 MISSING，不要求消除已有 REDUNDANT。

## 3. 阶段封装与结果

成功任务按 `draft → fixed-md → repair → recheck` 生成封装：

| 字段 | 含义 |
|---|---|
| schema_version | 外层协议版本 `e11e12-1` |
| job_id / trace_id | 同一 pipeline 任务的关联标识 |
| kind | 当前阶段名称 |
| commit | 当前阶段对应的 target_commit |
| status | 已完成阶段为 `SUCCEEDED` |
| data | 阶段结果，如 DRAFT 构建记录、MD 报告、修复计划或复验结果 |
| artifacts | 引用文件的逻辑 URI、SHA256 和字节数 |

顶层 `result.json` 保存任务状态、base_commit、target_commit、阶段索引和产物清单。成功 CLI 退出码为 0。本次内层过期请求的顶层状态为 FAILED，退出码为 1；已完成的 draft 阶段仍为成功。

流程 trace_id 与 DRAFT、BuildChecker 的内部 trace_id 分别记录。实验服务镜像 ID 与 DRAFT 构建出的程序镜像 ID 也分别记录。

## 4. artifact 标识与内容

URI 格式为 `artifact://job编号/任务内相对路径`，对应任务目录中的文件；sha256 对文件字节计算，bytes 为文件长度。逻辑 URI、Git 提交 SHA 和文件 SHA256 分别用于定位、版本绑定和内容一致性检查。

本次 mixed 固定报告阶段示例：

```text
artifact://job-87833a3a25f44995a79664e22be79270/fixed-md.json
```

mixed 的 result.json 记录：

pipeline 在消费固定报告阶段文件前通过 `load_artifact()` 核对期望摘要，再核对封装的目标提交。以上摘要来自本次 result.json 的阶段索引。

## 5. 错误与停止条件

| 错误码 | 条件与行为 |
|---|---|
| SCHEMA_MISMATCH | 外层 schema_version 不符，拒绝报告 |
| STALE_REPORT | 外层 commit 或内层 data.commit 不匹配，停止修复 |
| UPSTREAM_FAILED | 报告上游状态不是 SUCCEEDED |
| ARTIFACT_TYPE_MISMATCH | 输入 kind 不符合期望的 fixed-md |
| ARTIFACT_HASH_MISMATCH | 消费的阶段文件内容与期望摘要不一致 |
| DRAFT_FAILED | DRAFT 未成功，停止后续报告消费与修复 |
| REPAIR_REJECTED | 沙箱验证不接受候选 |
| RECHECK_FAILED | 动态重检仍有 MISSING，恢复目标 Makefile 的修复前字节 |
| OUTPUT_EXISTS | 输出目录已有内容，在任务执行前直接抛出异常；可能只有控制台错误日志 |

本次真实内层版本错误的返回为 `STALE_REPORT / Fixed report data commit mismatch`，仅生成 draft 阶段记录。外层过期个人测试模拟 DRAFT 成功，验证补丁生成和项目验证未调用。mixed 成功案例五项验证全部通过，动态重检无 MISSING。
